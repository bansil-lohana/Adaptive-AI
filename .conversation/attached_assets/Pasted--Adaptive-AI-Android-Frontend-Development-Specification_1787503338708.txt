# Adaptive AI — Android Frontend Development Specification

## ROLE

Act as a senior Google Android engineer, senior React Native engineer, senior UX/HCI engineer, and senior frontend architect.

Build a polished, production-quality **Android mobile application frontend prototype** called **Adaptive AI**.

This is the frontend/client application for an AI-powered adaptive HCI system.

The backend will be developed separately using **FastAPI in Cursor**.

Your responsibility in this task is ONLY the Android frontend/client.

Do not build the backend server.

Do not put AI API keys in the mobile application.

Do not directly connect the app to Gemini, OpenAI, or other AI providers.

Instead, create clean frontend service interfaces and mock implementations that can later be replaced with REST API calls to the FastAPI backend.

# 2. IMPORTANT FRONTEND/BACKEND SEPARATION

The backend will be developed separately.

The frontend must communicate with the backend through REST APIs.

Create an API abstraction such as:

```text
src/
├── api/
│   ├── client.ts
│   ├── aiApi.ts
│   ├── ocrApi.ts
│   └── historyApi.ts
```

For now, implement mock services.

Later these mock functions will be replaced with real FastAPI requests.

Example:

```typescript
askQuestion(prompt)
```

should currently return a mock response.

Later it will call:

```text
POST /api/chat
```

Similarly:

```text
analyzeImage()
    ↓
POST /api/analyze-image

extractText()
    ↓
POST /api/ocr

summarizeText()
    ↓
POST /api/summarize

translateText()
    ↓
POST /api/translate
```

Do not hardcode backend URLs throughout the application.

Create a single configurable API base URL.

Example:

```text
EXPO_PUBLIC_API_URL
```

Use environment configuration.

# 3. CORE PRODUCT CONCEPT

Adaptive AI is a multimodal AI assistant.

The user can interact using:

* Touch
* Text
* Voice
* Camera

The interface adapts based on:

* User preferences
* Accessibility settings
* Preferred interaction method
* Interaction behavior

The key HCI principle is:

> "The interface adapts to the user instead of forcing the user to adapt to the interface."

The frontend must make this adaptation clearly visible.

# 23. ADAPTIVE RULES

Implement rules such as:

```text

THEN increase voice action prominence

IF preferredMode = camera
THEN increase camera action prominence

IF simplifiedMode = true
THEN hide secondary actions

IF largeText = true
THEN increase typography scale

IF largeButtons = true
THEN increase button height

IF highContrast = true
THEN apply high contrast theme

IF reduceMotion = true
THEN reduce/disable non-essential animations

IF voiceFeedback = true
THEN enable automatic TTS where appropriate
```
