# 53. UNIVERSITY TIMETABLE & SMART CLASS REMINDER

Add a major feature called **Smart Schedule**.

The purpose of this feature is to help university students remember:

* Which class is coming next
* What subject they have
* What time the class starts
* What time it ends
* Which room/location the class is in
* Which teacher is teaching it, if available

The student should be able to upload a timetable image and have Adaptive AI convert it into a structured class schedule.

This feature must integrate naturally with the existing Adaptive AI and HCI concepts.

---

Add a **Schedule** section to the application.

The main navigation should become:


Prioritize usability over forcing too many icons into the bottom navigation.


Do not implement the backend.

# 83. ACCEPTANCE CRITERIA FOR SMART SCHEDULE

The feature is complete when:

* User can import a timetable image.
* User sees processing feedback.
* Mock OCR produces structured classes.
* User can review extracted classes.
* User can edit extracted information.
* User can delete incorrect classes.
* User can add missing classes.
* User can manually add classes.
* User can save the timetable.
* User can view today's schedule.
* User can view the weekly schedule.
* App calculates the next class.
* Home displays the next class.
* Reminder preferences can be changed.
* Notification permission is handled correctly.
* Local notifications can be scheduled for the prototype.
* User can enable/disable reminders.
* User can edit/delete classes.
* Schedule data persists locally.
* Simplified/accessibility modes affect the schedule UI.
* Assistant can access local schedule data for prototype queries.

# 84. UPDATED PRODUCT CONCEPT

Adaptive AI is now a multimodal adaptive HCI assistant with two major capabilities:

### 1. AI Accessibility Assistant

Camera + OCR + Voice + AI + TTS

### 2. Smart University Assistant

Timetable + Schedule + Context Awareness + Notifications

The application should demonstrate:

**"Understand the user, understand the context, and provide the right information at the right time."**

The Smart Schedule feature should feel like an integral part of Adaptive AI rather than a separate unrelated timetable application.
