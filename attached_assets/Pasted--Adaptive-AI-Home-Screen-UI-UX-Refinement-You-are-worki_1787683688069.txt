# Adaptive AI — Home Screen UI/UX Refinement

You are working on my existing **Adaptive AI mobile application**.

I want you to perform a **professional UI/UX refinement pass on the existing Home screen**.

## IMPORTANT — DO NOT REDESIGN FROM SCRATCH

This is a **refinement pass, NOT a complete redesign**.

Before making any changes:

1. Inspect the existing project structure.
2. Inspect the current Home screen implementation.
3. Inspect the existing navigation.
4. Inspect reusable UI components.
5. Inspect the existing color/theme system.
6. Inspect current data/state management.
7. Inspect existing icon libraries/components.
8. Identify what can be modified instead of creating duplicate components.

Then make the changes below while preserving the application's existing visual identity.

### Preserve

* Existing teal brand color
* Existing coral/peach color
* Existing navy AI surface
* Existing typography where appropriate
* Existing overall layout structure
* Existing bottom navigation style
* Existing reusable components
* Existing functionality unrelated to this request

Do NOT introduce a completely different design language.

Do NOT unnecessarily add new dependencies.

Do NOT rewrite working functionality just to achieve the UI changes.

Reduce the vertical padding/gap between the status bar/header area and the **ADAPTIVE AI** branding.

The current top area has too much empty space.

There should be **ONE clear primary header hierarchy**.


